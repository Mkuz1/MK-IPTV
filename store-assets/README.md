# Store assets

- `play/` — Google Play listing artwork: icon, feature graphic, phone/tablet/TV screenshots, TV banner,
  plus the HTML templates (`html/`, `v16/html/`) and raw captures (`src/`, `v16/raw/`) they are rendered from
  (`gen.py`, `render.sh`). `foreground-service-download-demo.mp4` is the video for the foreground-service declaration.
- App Store and Play screenshot sets rendered by `tools/store-graphics/render.js` are in `docs/store-graphics/`.

All artwork is AI-generated / rendered from the app UI. No Kids content.
Built apps (Android AAB, iPhone IPA) are attached to GitHub Releases, not committed.
