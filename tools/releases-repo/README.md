# MK IPTV — releases

Public download location for **MK IPTV**, an IPTV player for Xtream Codes playlists on Android phones, tablets, foldables, car head units and Google TV.

## Install

1. Open the [latest release](https://github.com/mkuz1/mk-iptv-releases/releases/latest) and download `MK-IPTV-<version>.apk`.
2. Open the file on your device and allow installing apps from this source when Android asks.
   - **Google TV / Android TV**: install with a file manager or "Downloader", or send the APK with "Send files to TV".

## Updates

Once installed, MK IPTV checks this page for new versions and updates itself from inside the app
(Settings → App updates). Every update is verified with a SHA-256 checksum and must be signed with
the same MK IPTV key as the installed app.

This repository only contains release files; the source code is private.
